# 🎬 Amazon Prime Content Analysis

> **Exploring content trends, ratings, genres and release patterns through data analysis.**

A portfolio project analyzing the Amazon Prime content dataset to uncover patterns in the platform's **content library, genres, ratings and release behavior**.

## 🎯 Objective

Transform raw streaming-content data into a structured analysis that highlights **content mix, audience-oriented patterns and catalog trends**.

## 🔍 Analysis Areas

- 🎭 Genre and category distribution
- ⭐ Rating distribution
- 📅 Release-year trends
- 🌍 Geographic/content distribution where available
- 🎬 Movies vs. TV shows
- 📚 Catalog composition and growth patterns

## 🛠️ Skills Demonstrated

**Data Cleaning · Exploratory Data Analysis · SQL / Data Analysis · Visualization · Business Storytelling**

## 📈 Project Approach

**Data Preparation → Exploration → Segmentation → Trend Analysis → Visualization → Insights**

## 💡 Portfolio Value

This project demonstrates the ability to take a familiar business dataset and turn it into a structured analytical story — a core workflow for a **Data Analyst / Business Analyst**.
